# 🚲 Bike Sales Dashboard – Excel

An interactive **Bike Sales Dashboard built in Microsoft Excel** to analyze bike sales performance, customer trends, and business insights through data visualization.

## 📊 Project Overview

This project focuses on transforming raw bike sales data into an interactive dashboard that makes it easier to understand sales patterns and identify key business insights.

## 🛠️ Tools & Techniques

* Microsoft Excel
* Data Cleaning
* Pivot Tables
* Pivot Charts
* Excel Formulas
* Data Visualization
* Interactive Filters / Slicers
* KPI Analysis

## 📈 Key Insights

* Sales performance analysis
* Customer and demographic analysis
* Product-wise sales performance
* Regional sales analysis
* Identification of sales trends
* Comparison of key performance indicators

## 🎯 Objective

To create a simple and interactive Excel dashboard that helps users quickly understand sales performance and make data-driven business decisions.
